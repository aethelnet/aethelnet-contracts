# Aethelnet Contracts 🗡️🛡️

The on-chain governance and token foundation for **Aethelnet** – the Sovereign AGI Grassroots Ecosystem.

## Architecture: The Forge
This repository contains the smart contracts for Aethelnet. It implements a hybrid governance model using **Zero-Knowledge Proofs (zk-SNARKs)** to enable anonymous, mathematically verifiable voting.

### Key Components:
- **`TheForge.sol`**: The primary governance contract. Allows users to create proposals and vote.
- **`AethelToken.sol`**: The base ERC-20 token representing network stake.
- **`ShieldedVote.circom`**: The core ZK-circuit (using Poseidon hashes) that allows voters to prove their identity and cast a vote without revealing their Ethereum address on-chain.
- **`Verifier.sol`**: A Solidity Verifier contract auto-generated by SnarkJS that checks the ZK proofs on-chain.

## Zero-Knowledge Voting (Dark Forest Governance)
We use `circom` and `snarkjs` to achieve absolute privacy. 
1. Voters register a public `commitment` (Hash of a private `secret` and `nullifier`).
2. When voting, they generate an off-chain ZK Proof validating they know the `secret`.
3. The circuit outputs a `nullifierHash` to prevent double-voting on the same proposal.
4. `TheForge.sol` verifies the Groth16 proof. If valid, the vote is counted. The voter's identity remains completely hidden.

## Getting Started

### Prerequisites
- Node.js & npm
- Hardhat
- Circom Compiler (`circom`)

### Setup & Compilation
1. **Install dependencies:**
   ```bash
   npm install
   npm install circomlib circomlibjs snarkjs
   ```

2. **Run the ZK Trusted Setup & Generate Verifier:**
   ```bash
   chmod +x scripts/compile_zk.sh
   ./scripts/compile_zk.sh
   ```
   *(This will compile the `.circom` circuit, run the Powers of Tau ceremony, and generate `contracts/Verifier.sol`)*

3. **Simulate a Shielded Vote:**
   ```bash
   npx hardhat run scripts/simulate_vote.js
   ```
